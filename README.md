# Gyro Cursor

## Bill of Materials

Prices up to date as of Nov 4 2026

### Required Components

| Name                                             | Description                                                           | Price  |
| ------------------------------------------------ | --------------------------------------------------------------------- | ------ |
| Adafruit ESP32-S3 Feather (4MB Flash, 2MB PSRAM) | The main controller                                                   | $17.50 |
| Adafruit USB Host FeatherWing                    | Extends the controller with a USB port                                | $14.95 |
| FeatherWing Doubler                              | A breadboard like solution to conjoin the controller nad the USB host | $7.50  |
| Elgato Stream Deck Pedal                         | Foot switches to switch between cursor modes                          | $79.99 |

### Optional Accessories

| Name                           | Description                                                                                                                                                                 | Price |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| SUNGUY Right Angle USB C Cable | You may want to use the Elgato Stream Deck rotated 180° from what's advertised, in which case a right angle USB C cable would stop you from stepping on the cable too often | $9.59 |
